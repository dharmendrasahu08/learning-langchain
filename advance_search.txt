Creating Sparse vector using powershell collection candidate_profiles
I faced issue while creating sparse vector using qdrant console that reason created by powershell

$body = @'
{
  "vectors": {
    "dense": {
      "size": 1536,
      "distance": "Cosine"
    }
  },
  "sparse_vectors": {
    "bm25": {
      "modifier": "idf"
    }
  },
  "on_disk_payload": true
}
'@

Invoke-RestMethod -Method Put `
  -Uri "http://localhost:6333/collections/candidate_profiles" `
  -ContentType "application/json" `
  -Body $body
